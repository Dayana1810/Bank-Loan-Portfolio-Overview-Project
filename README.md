# Bank Loan /Debit And Credit Bank Analysis Overview-Project

## 1.Bank Loan Portfolio Overview Dashboard 

This dashboard provides an overall view of the bank's loan portfolio and financial performance. It tracks total loan amount funded, total applications, total amount received, and average interest rate. It also presents disbursement trends, product group-wise loans, branch-wise performance, and loan status distribution. These insights help evaluate lending performance, understand loan demand, and monitor the bank's portfolio.

## 2.Demographic Loan Portfolio Analysis Dashboard

This dashboard analyzes loan distribution based on customer demographics, including state, age group, and religion. It highlights the top state by loan amount, loan distribution across customer groups, average funded volume, and loan exposure by state. It also compares loan purposes across age groups, helping understand customer borrowing patterns and demographic differences in loan demand.

## 3.Loan Risks & Delinquency Analytics Dashboard

This dashboard focuses on loan defaults, delinquent customers, and loan risk assessment. It tracks default loan counts, default rates, delinquent clients, delinquent loan rates, and unverified loans. It also analyzes grade-wise loan distribution, loan status, loan maturity, and delinquency trends to help identify potential credit risks and support better lending decisions. 

## 4. Bank Transaction & Cash Flow Overview Dashboard

This dashboard provides an overview of banking transactions, credit and debit amounts, and cash flow performance. It includes total credit, total debit, net cash flow, account activity ratio, monthly transaction trends, branch-wise transaction amounts, transaction method distribution, and transaction volumes by bank. It helps analyze financial movements, compare branch performance, and understand customer transaction patterns.

## 5. Suspicious Transaction & Risk Monitoring Dashboard

This dashboard focuses on identifying suspicious transactions and monitoring high-risk banking activities. It analyzes high-risk transaction counts, suspicious transaction frequency, high-risk amount share, branch growth rates, and transaction triggers. The dashboard helps identify risky transaction patterns, monitor monthly trends, and compare risk levels across branches.

## Overall Project Summary

This banking analytics project consists of five interactive dashboards developed to analyze banking transactions, cash flow, suspicious activities, loan risks, customer demographics, and loan portfolio performance. The dashboards use KPIs, charts, graphs, and filters to transform banking data into meaningful business insights. They help monitor financial performance, identify potential risks, understand customer behavior, and support data-driven decision-making.

## Tools and Technologies
- Excel: Data cleaning, preparation, and initial analysis.
- QL / MySQL: Data extraction, filtering, and querying.
- Power BI: Interactive dashboards, KPI cards, and data visualization.
- Tableau: Interactive charts, visual analytics, and dashboard development.
